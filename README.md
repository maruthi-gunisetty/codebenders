# CASHFLOW AI — Multi-Business Financial Operations & Intelligence Platform

> **Tagline:** Your Business. Under Control.  
> Institutional-grade multi-business financial operations, 30–90 day cash flow forecasting, and automated payment follow-up platform. Built for Ace Builders' Hackathon 2026.

---

## Overview

**CASHFLOW AI** brings customer management, invoicing, payment tracking, operational expenses, and forward-looking cash flow forecasting into one unified platform. It features three dedicated, tailored business workspaces running on a single financial engine:

1. **Education & Coaching Workspace:** Student rosters, batch scheduling, fee due cycles, fee defaulters tracking, and 1-tap WhatsApp payment reminders.
2. **Salon & Beauty Studio Workspace:** Live appointment scheduler, stylist commission tracking (20%–30%), and counter service billing.
3. **Retail & Kirana Store Workspace:** High-speed POS counter billing, real-time inventory deductions with low-stock warnings, and Udhar Khata (Customer Credit Ledger).

---

## Key Features

- **Financial Overview Dashboard:** Real-time liquid cash, bank balances, total billed revenue, pending receivables, and overdue aging tracking.
- **Cash Flow Forecasting Engine:** Deterministic 30, 60, and 90-day cash trajectory projections modeling verified inflows against recurring overhead.
- **Interactive What-If Scenario Simulator:** Real-time parameter testing (collection delays, rent increases, sales slowdowns, emergency outflows) with baseline comparison charts.
- **AI Business Copilot:** Deterministic ledger assistant answering questions on debts, runway, and affordability with 1-click WhatsApp reminder drafting.
- **Design System ("Precision Ledger"):** Light, high-trust fintech aesthetic styled with Plus Jakarta Sans, Inter, and JetBrains Mono tabular numerals.

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/maruthi-gunisetty/codebenders.git
cd codebenders

# Install dependencies
npm install

# Start development server with network exposure
npm run dev -- --host
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
npm run preview
```
